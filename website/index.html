手机和 Mac 能用吗？
PaperTodo 是原生 Windows 桌面应用，主要面向 Windows 10 / 11 x64。官网可以在手机上体验，但这个演示不是手机版应用。历史 Releases 中有 Windows 7 SP1 x64 Best Effort 包，不属于正式支持范围。

      
应该下载哪个文件？
优先选择以 self-contained.exe 结尾的文件，已包含运行时。体积更小的 no-runtime.exe 需要 .NET 10 Desktop Runtime（x64）。请把程序放进有写入权限的专用文件夹，不要放在临时或只读目录。

      
怎么备份和换电脑？
退出 PaperTodo 后，复制整个程序文件夹。保留 data.json、note-assets.lmdb，以及存在时的插件目录，让纸片、图片和插件数据一起迁移。本页演示不会生成这些数据文件。

      
Windows 提示安全警告怎么办？
Windows 可能对未签名或信誉不足的程序提醒。请只从本仓库 Releases 下载，核对来源、版本与提供的校验值后，再决定是否运行。不要关闭系统防护，也不要运行来源不明的副本。

      
免费吗？公司可以统一部署吗？
个人可免费使用，包括在工作中作为个人工具使用。普通公司统一部署需要商业许可；教育等符合条件的机构另有许可。完整范围请以项目许可证为准。 查看许可证 ↗
