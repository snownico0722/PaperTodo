# Bottom Bar Counts · API 2.5

Copy this directory into PaperTodo's `plugins` directory and restart PaperTodo. Open the paper menu on an existing note or to-do and check **Bottom Bar Counts** under **Bottom bar plugins**.

A note shows its character count. A to-do shows the number of unfinished items and a clickable **Progress** item. Narrow the window to see how the host keeps the higher-priority items. Bind another paper to the same plugin to see both papers share a single Runtime.
