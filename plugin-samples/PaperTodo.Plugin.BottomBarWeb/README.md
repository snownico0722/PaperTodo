# Bottom Bar Counts · API 2.5

Copy this directory into PaperTodo's `plugins` directory and restart PaperTodo. Enable **Bottom Bar Counts** in **Settings → Plugins**. No plugin paper is needed. The manifest targets both notes and to-dos.

A note shows its character count. A to-do shows the number of unfinished items and a clickable **Progress** item. Narrow the window to see how the host keeps the higher-priority items. Create another note or to-do to see its counts appear automatically. Disabling this plugin removes its counts from all papers.
